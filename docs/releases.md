# Сборки и публикация

Обычные изменения проверяет `Build and test` на трёх ОС. Ручной workflow `Package installers` собирает DEB, EXE и DMG как артефакты GitHub Actions; он не публикует их автоматически как релиз.

Первый запуск workflow 2026-09-22 успешно собрал все три артефакта. Это подтверждает сборку пакетов, но не установку и работу микрофона на Windows и macOS.

Перед выпуском проверить каждый пакет на реальном устройстве соответствующей ОС: установку без отдельной Java, запуск, выбор микрофона, распевку, локальное сохранение истории и удаление программы. Неподписанные установщики могут показывать системное предупреждение; подпись требуется решить до публичного выпуска. После проверки создать версию и GitHub Release вручную. Аудиоданные и экспериментальные веса моделей не включать в пакет.

Версия проекта задаётся свойством `version` в `build.gradle`: она встраивается в заголовки окна и передаётся `jpackage`. После изменения запускаемого кода выполнять `./gradlew localRelease`, затем проверять запуск обновлённого файла из `build/jpackage/`. Папка автономного приложения сохраняет постоянное имя, поэтому путь к запускаемому файлу не меняется при обновлении версии.
