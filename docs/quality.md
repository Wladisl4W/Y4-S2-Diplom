# Проверка качества

## Автоматические тесты

`./gradlew test` проверяет детектор на синтетических нотах, тишине и шуме, перевод в центы и временную шкалу графика. Для каждого нового алгоритма добавлять тесты на входы и ожидаемый результат, включая паузы и ошибочные данные.

## Измерение высоты и задержки

Хранить отдельно от репозитория контрольные WAV: синусоидальные ноты, записи реального пения и случаи с шумом. Для каждого примера указывать эталонную частоту или размеченную нотную линию. Измерять медианную абсолютную ошибку в центах, долю кадров с ошибкой более полутона, долю пропущенных нот и задержку от начала звука до обновления UI. Фиксировать модель микрофона, ОС, версию программы и метод разметки.

## Анализ песен

Для выделения вокала оценивать слышимые утечки аккомпанемента и потери голоса. Для нотной линии измерять совпадение по времени и высоте с проверенной вручную разметкой. Ошибки разбора песни и ошибки исполнения пользователя показывать отдельно.

## Ручная проверка перед релизом

Запуск и остановка микрофона; смена устройства; пение устойчивой ноты, перехода и паузы; доступность текста и элементов при изменении размера окна; установка пакета без системной Java. Для распевок: прохождение, пропуск нот, результаты и история. Для песен: импорт, отмена, ошибки обработки и сравнение с голосом.
