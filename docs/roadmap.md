# Этапы проекта

1. Основа: публичный репозиторий, воспроизводимая сборка, тесты, документация и единая тема.
2. Распевки: целевые ноты, обратная связь, результаты и локальная история.
3. Эксперимент MP3: небольшой набор файлов с разрешённым использованием и вручную проверенной разметкой; сравнение локальных методов разделения и транскрипции.
4. Песни: фоновая обработка, нотная линия и сравнение живого пения с полученной мелодией.
5. Дипломный релиз: пользовательские проверки и пакеты для Windows, macOS и Linux.

Закрывать этап только после обновления тестов, документации и ручной проверки на соответствующей платформе. Пользовательские песни и записи не публиковать в репозитории.
