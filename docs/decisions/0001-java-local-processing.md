# 0001. Java и локальная обработка

Статус: принято, 2026-09-22.

Главное приложение реализовано на Java 21 и JavaFX. Захват голоса и определение высоты выполняются локально через Java Sound и YIN. Это соответствует предпочтению автора диплома и позволяет запускать основной сценарий без сервера. Для тяжёлого анализа песен допускается локальный Python процесс, если эксперимент покажет преимущество существующих моделей; граница обмена должна быть явной, а ошибки и отсутствие модуля понятными пользователю.
