# Эксперимент локального анализа MP3

Статус: исследование. С версии 1.12 приложение позволяет открыть MP3/WAV и просмотреть черновую линию, полученную Java YIN из полной смеси через системный FFmpeg. Анализ выполняется в фоне и отменяется; файл не копируется в репозиторий и не отправляется в сеть. Пение по этой линии и оценка пока отключены. Системный FFmpeg нужен отдельно: установщик включает Java, но не FFmpeg.

## Следующий контрольный набор

Для испытания на настоящих песнях выбран [MedleyDB](https://medleydb.weebly.com/downloads.html): он содержит смеси, отдельные дорожки и разметку высоты мелодии. Полное аудио выдаётся по запросу; лицензия CC BY-NC-SA 4.0 допускает некоммерческое исследование, но авторы просят не публиковать набор повторно. Аудио останется вне репозитория. Публичный пример набора может служить проверкой формата до получения полного доступа.

Не вся разметка Melody 1 относится к вокалу. Перед замером нужно выбрать записи, где ведущая мелодия действительно спета, сверить это по метаданным дорожек и прослушать участки с паузами. Для каждой записи сравнить одну и ту же временную сетку эталона с Basic Pitch на смеси, Basic Pitch на отделённом вокале и Java YIN на отделённом вокале. Отдельно считать точность высоты на вокальных кадрах, пропуски голоса, ложный голос на паузах и время обработки. Список выбранных файлов, параметры и результаты сохранить в `docs/measurements/`; сами записи и веса моделей не коммитить.

## Кандидаты

- Выделение вокала: [Audio Separator](https://github.com/nomadkaraoke/python-audio-separator) с моделью `UVR_MDXNET_KARA_2.onnx` на CPU. Модель хранится отдельно от репозитория.
- Извлечение нот: [Basic Pitch](https://github.com/spotify/basic-pitch), локальная модель TFLite.
- Базовое сравнение: Basic Pitch напрямую на смеси, без выделения вокала.

## Воспроизведение короткой проверки

Нужны Python 3.10, ffmpeg, `basic-pitch==0.4.0`, `audio-separator==0.47.0`, CPU PyTorch, `numpy<2` и `setuptools<81`. Запустить `python scripts/experiment_mp3.py`. Скрипт сам генерирует пятинотную мелодию поверх двух тонов сопровождения, кодирует её в MP3, сравнивает извлечение нот до и после отделения вокала, удаляет временное аудио и печатает JSON с событиями и временем обработки. Модель загружается в `~/.local/share/intonation-trainer/models` при первом запуске. Для полностью автономной работы модель должна уже находиться там.

Это проверка совместимости компонентов, а не доказательство качества на реальном пении. Перед интеграцией в режим песен нужны несколько разрешённых для исследования песен с проверенной вокальной разметкой, сравнение моделей и пользовательская проверка нотной линии. Отдельно проверить условия использования весов модели и не включать чужие аудиофайлы в публичный репозиторий.

## Результат первой проверки (Linux, CPU, 2026-09-22)

На пятисекундной синтетической смеси обе цепочки нашли все пять ожидаемых нот в середине соответствующих секунд. Basic Pitch без разделения выдал 10 событий, из них 5 с иной высотой; после выделения вокала — 12 событий, из них 7 с иной высотой. Время обработки составило примерно 1,0 с и 10,9 с соответственно; во втором случае включена загрузка модели из локального кэша. Это один искусственный пример, поэтому цифры нельзя обобщать на реальные песни.

**Решение:** не включать автоматическую оценку пения по MP3 в релиз. Разделение вокала само по себе не устранило ложные ноты. Следующий шаг — разрешённые реальные записи с эталонной разметкой и проверка выбора главной вокальной линии. До такой проверки вкладка «Песни» честно сообщает о статусе исследования.

## Проверка на размеченном вокале

Использован [Vocadito v3](https://zenodo.org/records/5578807), набор коротких записей сольного пения с покадровой разметкой высоты. Аудио хранится только локально. `scripts/evaluate_vocadito.py` сравнивает события Basic Pitch с эталонной F0 примерно каждые 100 мс: совпадением считается ошибка не более одного полутона. Это предварительная оценка событий нот, не итоговая метрика качества пения.

| Запись | Покрытие вокальных кадров | Верная высота на вокальных кадрах | Ложный голос на тишине |
| --- | ---: | ---: | ---: |
| Vocadito 1, только голос | 87,7% | 87,2% | 13,5% |
| Vocadito 2, только голос | 92,6% | 90,8% | 0% |
| Vocadito 3, только голос | 88,8% | 88,0% | 21,9% |

На Vocadito 1 был добавлен синтетический аккомпанемент из двух тонов и сохранён MP3. Прямой анализ правильно определил высоту на 65,4% вокальных кадров; после отделения вокала — на 68,7%. В обоих случаях детектор показывал ложный голос на 96,8% размеченных участков тишины. Прямой анализ занял около 1,1 с, разделение и анализ — около 38 с для записи длительностью 33 с на CPU этого ноутбука.

Вывод ограничен одной искусственно дополненной записью: существующая цепочка не умеет надёжно выбирать именно ведущий голос и определять паузы. Для дипломной версии нужны другие модели или отдельный алгоритм выбора вокальной линии, измерения на нескольких настоящих многодорожечных песнях и проверка результата человеком перед сравнением с пением пользователя.

## Расширенная проверка Vocadito (40 записей, 2026-09-23)

Команда `python scripts/evaluate_vocadito.py /tmp/vocadito --ids {1..40}` проверила 40 записей сольного вокала. Среднее **по записям** покрытие вокальных кадров составило 80,8%, правильная высота в пределах одного полутона — 78,4%, ложный голос на размеченной тишине — 15,7%. Разброс правильной высоты между записями: 50,0–93,4%. Это solo-аудио без аккомпанемента; результат нельзя переносить на обычные MP3-песни.

`python scripts/compare_note_filters.py /tmp/vocadito` сравнивает пороги уверенности Basic Pitch на первых 20 записях и проверяет выбранный порог на оставшихся 20. Лучшим по F1 на обучающей части оказался исходный порог 0,0. На отложенной части правильная высота была в 78,8% вокальных кадров, ложный голос — в 16,6% кадров тишины, F1 = 0,832. Порог 0,5 сократил ложные ноты на обучающей части с 13,6% до 10,2%, но снизил долю правильной высоты с 80,6% до 69,8%. Простое повышение порога не решает проблему. Следующая проверка должна включать настоящие песни с аккомпанементом и разметкой пауз/ведущего вокала.

На тех же 40 сольных WAV Java YIN без сглаживания обнаружил голос на 86,3% вокальных кадров, правильно определил высоту в пределах полутона на 84,6% и ложно нашёл голос на 10,0% кадров тишины. Это выше результата Basic Pitch на сольных файлах, однако методы запускались отдельными скриптами и на несколько различающихся граничных кадров; прямое сравнение приблизительное. Исходные цифры и команда — в [замере YIN](measurements/2026-09-23-vocadito-yin.md). Перед выбором цепочки для MP3 нужно сравнить оба метода на одном и том же отделённом вокале из реальных песен.
