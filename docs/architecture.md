# Архитектура

## Назначение

Приложение помогает начинающему певцу видеть высоту голоса и тренировать попадание в ноты. Основной код и интерфейс написаны на Java 21 и JavaFX. Анализ аудио выполняется на устройстве пользователя.

## Текущий поток данных

`MicrophoneCapture` читает моно PCM 44,1 кГц из выбранного `TargetDataLine`. `YinPitchDetector` оценивает основную частоту кадра. Результаты передаются в очередь, которую считывает JavaFX поток. `PitchTimeline` хранит временные отметки и высоту; `PitchChart` отрисовывает последние 10 секунд. `Note` переводит частоту в равномерно темперированный строй A4 = 440 Гц.

Аудиопоток не сохраняется на диск и не передаётся по сети. JavaFX элементы изменяются только из JavaFX потока.

## Границы компонентов

- `audio`: устройства, чтение PCM, выделение высоты и музыкальные обозначения.
- `exercise`: описание упражнения, состояние выполнения, оценка и локальная история.
- `song`: импорт файла, извлечённая нотная линия и сравнение с живым пением. Анализ файла запускается в фоне.
- UI: навигация, элементы и тема JavaFX CSS. UI не содержит алгоритмы оценки высоты.

## Неизвестные вопросы

Локальное выделение вокала и транскрипция MP3 требуют измерения качества и ресурсов на нескольких песнях. Выбор и лицензии моделей фиксируются после эксперимента; до этого модель не включается в дистрибутив.
