# Архитектура

## Назначение

Приложение помогает начинающему певцу видеть высоту голоса и тренировать попадание в ноты. Основной код и интерфейс написаны на Java 21 и JavaFX. Анализ аудио выполняется на устройстве пользователя.

## Текущий поток данных

`MicrophoneCapture` читает моно PCM 44,1 кГц из выбранного `TargetDataLine`. `YinPitchDetector` оценивает основную частоту кадра. `MicrophoneController` выбирает и запоминает устройство, проводит пробу сигнала и передаёт измерения через очередь в JavaFX поток. `PitchTimeline` хранит временные отметки и высоту; `PitchChart` всегда отрисовывает этот живой поток. `PitchViewport` задаёт общую временную шкалу для голоса и целевых нот распевки. `Note` переводит частоту в равномерно темперированный строй A4 = 440 Гц.

Аудиопоток не сохраняется на диск и не передаётся по сети. JavaFX элементы изменяются только из JavaFX потока.

## Границы компонентов

- `audio`: устройства, чтение PCM, выделение высоты и музыкальные обозначения.
- `exercise`: описание упражнения, состояние выполнения, оценка по равным временным интервалам всей целевой линии и локальная история. Паузы между частями набора исключены из оценки.
- `song`: `SongPipeline` ограничивает запись десятью минутами и разделяет её локальной моделью на вокал и инструментал. `LeadVocalTranscriber` запускает локальный Basic Pitch, строит несколько нотных кандидатов и выбирает непрерывную ведущую линию; альтернативы доступны для ручного выбора. При ошибке модуля используется прежний `SongAnalyzer` с YIN. `SongPlayback` смешивает две выровненные дорожки с независимыми переключателями. `SongChartState` накладывает выбранную линию на общий график. Ручные правки сохраняются локально и привязаны к содержимому аудиофайла; оценка по песне не включена.
- UI: `IntonationApp` собирает окно, связывает общее полотно, транспорт и страницы. `WarmupLibrary` владеет каталогом, настройками и предпросмотром распевок. `WarmupController` ведёт попытку, оценку, фортепианные подсказки и историю, возвращая неизменяемый снимок состояния для интерфейса. `SongLibrary` владеет импортом, проверкой и ручной правкой нот; готовые дорожки передаются на общее полотно. Тема находится в JavaFX CSS. UI не содержит алгоритмы оценки высоты.

## Неизвестные вопросы

Локальное выделение вокала и транскрипция MP3 требуют измерения качества и ресурсов на нескольких песнях. Выбор и лицензии моделей фиксируются после эксперимента; до этого модель не включается в дистрибутив.

Выбор распевки задаётся `ExerciseCatalog`: отдельный паттерн либо набор из нескольких паттернов с границами частей. Набор разворачивается в одну последовательность нот для `ExerciseSession`, поэтому время, линия голоса и оценка используют ту же шкалу. `ExerciseChartState` хранит время старта и границы частей для наложения целей на общий `PitchChart`; отдельной линии голоса для распевок нет.

`PlaybackClock` остаётся единственным источником времени для очереди голоса, распевки, песни и графика. При паузе приложение очищает накопленные измерения и глушит пианино; при возобновлении контроллеры продолжают с того же логического момента. После завершения распевки `ExerciseChartState` сохраняет цели на их исходном месте, пока они не покинут видимую область.
