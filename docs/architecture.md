# Архитектура

## Назначение

Приложение помогает начинающему певцу видеть высоту голоса и тренировать попадание в ноты. Основной код и интерфейс написаны на Java 21 и JavaFX. Анализ аудио выполняется на устройстве пользователя.

## Текущий поток данных

`MicrophoneCapture` читает моно PCM 44,1 кГц из выбранного `TargetDataLine`. `YinPitchDetector` оценивает основную частоту кадра. Результаты передаются в очередь, которую считывает JavaFX поток. `PitchTimeline` хранит временные отметки и высоту; `PitchChart` всегда отрисовывает этот живой поток. `PitchViewport` задаёт общую временную шкалу для голоса и целевых нот распевки. `Note` переводит частоту в равномерно темперированный строй A4 = 440 Гц.

Аудиопоток не сохраняется на диск и не передаётся по сети. JavaFX элементы изменяются только из JavaFX потока.

## Границы компонентов

- `audio`: устройства, чтение PCM, выделение высоты и музыкальные обозначения.
- `exercise`: описание упражнения, состояние выполнения, оценка и локальная история.
- `song`: экспериментальный анализ MP3/WAV в фоне. `SongAnalyzer` запускает локальный FFmpeg для декодирования смеси в PCM и использует YIN для построения черновой нотной линии. Сравнение с живым пением ещё не включено.
- UI: навигация, элементы и тема JavaFX CSS. UI не содержит алгоритмы оценки высоты.

## Неизвестные вопросы

Локальное выделение вокала и транскрипция MP3 требуют измерения качества и ресурсов на нескольких песнях. Выбор и лицензии моделей фиксируются после эксперимента; до этого модель не включается в дистрибутив.

Выбор распевки задаётся `ExerciseCatalog`: отдельный паттерн либо набор из нескольких паттернов с границами частей. Набор разворачивается в одну последовательность нот для `ExerciseSession`, поэтому время, линия голоса и оценка используют ту же шкалу. `ExerciseChartState` хранит время старта и границы частей для наложения целей на общий `PitchChart`; отдельной линии голоса для распевок нет.
