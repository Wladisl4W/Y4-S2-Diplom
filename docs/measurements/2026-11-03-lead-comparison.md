# Проверка выбора ведущей вокальной партии — 03.11.2026

## Данные и условия

Проверены 40 независимых сольных фрагментов [Vocadito v3](https://zenodo.org/records/5578807) с разметкой F0 и нот A1, а также 17 фрагментов с наложенными голосами из шести песен [MedleyVox](https://zenodo.org/records/7984549). Для последних использована [разметка MELODY1 MedleyDB](https://medleydb.weebly.com/downloads.html) только там, где стем с первым мелодическим рангом совпадает с объявленным главным голосом MedleyVox. Это приближение: источник MELODY1 может меняться внутри фрагмента. Аудио, веса моделей и промежуточные файлы хранятся вне репозитория. MedleyDB разрешает некоммерческое исследовательское использование и просит не переиздавать данные; мы не включаем их в GitHub.

Vocadito разделён по номеру фрагмента: 20 нечётных для разработки, 20 чётных для проверки. Многоголосные данные разделены **по песням**: FacesOnFilm, FamilyBand и LizNelson_Rainfall для разработки; ClaraBerryAndWooldog, Meaxic и NightPanther для проверки. Условия и показатели каждого фрагмента сохранены в [JSON](2026-11-03-lead-results.json).

Архивы скачаны с официальных страниц и сверены по MD5: Vocadito `dea40fd18f14d899643c4ba221b33a46`, MedleyVox `b1c8b3eddfbe2bfe06f84a89e2a83e3e`, открытый пример MedleyDB `dbb5b4ff5122233915d04cab4486ead1`. Аннотации MedleyDB взяты из официального репозитория, коммит `537bb7b`; метаданные MedleyVox — коммит `a185cd5`. Среда: Linux x86_64, AMD Ryzen 5 7520U, Basic Pitch 0.4.0, локальная обработка на CPU. Настройки Basic Pitch: `onset_threshold=0.45`, `frame_threshold=0.26`, `minimum_note_length=100` мс, диапазон MIDI 36–96.

## Методика

Каждый файл пропущен через Basic Pitch один раз; предложения нот сохранены во внешнем кэше. Текущий выбор лида версии 1.18.0 и три заранее заданных варианта применены к **одним и тем же** предложениям. Верная высота означает отклонение не более 50 центов на размеченном вокальном кадре; пропуск — отсутствие предложенной ноты там; ложный голос — любая нота в кадре, размеченном как пауза ведущей мелодии. Для сольных фрагментов также измерено совпадение нотных событий: одинаковая нота, начало в пределах 0,1 с и конец в пределах 0,2 с. Средние ниже — арифметические средние по фрагментам, не по кадрам. У Vocadito два независимых нотных аннотатора; здесь выбран A1, поэтому F1 не является абсолютной оценкой музыкальной правильности.

## Сравнение вариантов и решение

Варианты `balanced`, `cautious` и `continuity` меняли вес уверенности модели, длительности, регистра, непрерывности и выбора тишины. Полные параметры есть в JSON. На многоголосной группе разработки текущий алгоритм дал 40,7% верной высоты; варианты — 39,6%, 39,5% и 39,4%. На проверочных песнях `cautious` поднял среднее до 42,7% и снизил ложный голос с 66,2% до 64,5%, но одновременно ухудшил результат разработки и сольные записи (66,4% и 64,6% верной высоты вместо 67,6% и 66,0%). `balanced` почти сохранил точность на проверке, но также уступил на разработке. **Ни один вариант не принят как новый алгоритм приложения.** Текущие настройки 1.18.0 остаются значениями по умолчанию.

Главный практический вывод: перенастройка нескольких весов не решила выбор певца при гармониях. Следующий эксперимент должен учитывать признаки голоса или исследовать отдельное разделение главного и фоновых вокалов. До такой проверки пользователь должен видеть альтернативы и иметь возможность править линию вручную.

## Воспроизведение

Скачать официальные архивы в каталог вне репозитория, сверить MD5, распаковать Vocadito и папку `MedleyVox/rest`, получить официальные метаданные и аннотации. Для анализа нужен Python из `scripts/setup_song_analysis.sh`. В примере ниже `DATA` — каталог распакованных наборов, `ENV_PYTHON` — путь к установленному локальному Python:

```bash
python3 scripts/prepare_lead_manifest.py \
  --vocadito "$DATA/vocadito-v3" \
  --medleyvox "$DATA/MedleyVox/rest" \
  --config "$DATA/MedleyVox-code/testset/testset_config/V1_rest_vocals_only_config" \
  --annotations "$DATA/medleydb-code/medleydb/data/Annotations" \
  --output-dir "$DATA/lead-eval"

"$ENV_PYTHON" scripts/evaluate_lead_candidates.py \
  "$DATA/lead-eval/manifest.csv" \
  --cache "$DATA/lead-eval/cache" \
  --output "$DATA/lead-eval/results.json"
```

Скрипты не обращаются к сетевому сервису во время распознавания. Повторный запуск с тем же кэшем использует сохранённые предложения Basic Pitch, что позволяет сравнивать выбор линии без повторного распознавания аудио.
