# Тренировка интонации

Локальное десктоп приложение для начинающих певцов. Оно показывает текущую ноту, отклонение в центах и историю высоты голоса. Есть четыре паттерна распевок с выбором опорной ноты от C2 до C5 по полутонам, набор из них, обратная связь и локальная история занятий. Экспериментальный режим песен показывает черновую нотную линию MP3 без оценки пения.

## Запуск

Нужен JDK 21. Для запуска из исходников выполните `./gradlew run` (Windows: `gradlew.bat run`). При первом запуске приложение предложит выбрать микрофон: выберите устройство, нажмите **«Проверить микрофон»**, спойте протяжную ноту и убедитесь, что появилась распознанная нота. Затем нажмите **«Сохранить и начать»**. Устройство запоминается на этом компьютере и при следующих запусках включается автоматически. Сменить его можно через **«Настройки»**. Если устройство отсутствует или недоступно, приложение покажет сообщение и предложит открыть настройки.

На главном полотне **«Живой голос»** вертикальный курсор закреплён по центру; сетка и линия голоса движутся относительно него. Кнопка **«Пауза / Продолжить»** останавливает и возобновляет полотно вместе с текущей распевкой. Каждая строка сетки охватывает диапазон одной ноты (±50 центов), а границы проходят между нотами. В каталоге **«Распевки»** выберите паттерн или набор, затем комфортную опорную ноту от C2 до C5. Выберите маршрут: один проход, подъём на два или четыре полутона с возвращением вниз. Нажатие карточки сразу открывает главное полотно с целевыми нотами и двухсекундным отсчётом. Между повторениями рисунка есть участок перехода без целевой ноты. Во время распевки две независимые галочки включают и выключают фортепианные целевые ноты и два аккорда перехода. Для точной оценки с включённым звуком используйте наушники. Кнопка «Начать выбранное» запускает выбранное упражнение ещё раз; образец можно прослушать отдельно. Набор состоит из четырёх паттернов подряд. Целевые полосы и линия голоса движутся по одной шкале времени. Зелёный участок линии означает попадание в диапазон ±50 центов, коралловый — промах. Кнопка «Прервать» отменяет попытку. Результат сохраняется локально в `~/.intonation-trainer/progress.csv`; последний результат показан под графиком, остальные доступны через «История».

Во вкладке **«Песни · эксперимент»** можно открыть локальный MP3 или WAV. Сначала локальная модель разделяет запись на вокал и инструментал, затем YIN строит ноты только по вокалу за первые 10 минут файла. Разбор идёт в фоне и отменяется. Выделите ошибочную ноту в списке, чтобы сдвинуть её на полутон или удалить. Кнопка **«Петь на главном полотне»** переносит линию на общий график и запускает песню после двухсекундного отсчёта. На главном полотне отдельно включаются и выключаются инструментал и вокал; общая пауза останавливает график и звук. При использовании колонок микрофон может улавливать воспроизведение, поэтому для тренировки рекомендуются наушники.

Для этого экспериментального режима нужны системный `ffmpeg`, локальный Python 3.10 и Audio Separator с моделью `UVR_MDXNET_KARA_2.onnx`. На Linux подготовить окружение можно командой `bash scripts/setup_song_analysis.sh` при установленных `uv`, Python 3.10 и FFmpeg. Python, модель и FFmpeg пока не входят в установщик. Данные остаются на устройстве, промежуточные дорожки удаляются при закрытии программы. Автоматически полученные ноты могут быть ошибочными; оценка пения по песне пока не рассчитывается.

Микрофон должен поддерживать моно PCM 44,1 кГц. Если приложение не видит устройство, проверьте разрешение на микрофон в настройках ОС и обновите список в настройках приложения.

`./gradlew test` выполняет тесты детектора, нотной шкалы, графика и упражнений. `./gradlew build` собирает приложение и запускает тесты. Пользовательские аудиофайлы и локальные результаты исключены из репозитория.

## Пакеты

Текущая версия отображается в названии окна и внутри приложения. Для локальной проверенной сборки выполните `./gradlew localRelease`; задача запускает тесты и создаёт установщик текущей ОС. Версию меняют в одном месте: свойство `version` в `build.gradle`.

На Linux автономное приложение запускается файлом `build/jpackage/Intonation Trainer/bin/Intonation Trainer` после `./gradlew jpackageImage`. Команда `./gradlew jpackage` создаёт установщик `.deb` в `build/jpackage/`. Оба варианта включают Java и не требуют установленного JDK. Для DEB на Linux требуется `fakeroot`. Ручной workflow в GitHub Actions собирает установщики трёх ОС как артефакты. Их необходимо проверить на реальном оборудовании перед публикацией релиза; порядок описан в [docs/releases.md](docs/releases.md).

## Ограничения

Живое пение рассчитано на один голос в диапазоне 60–1000 Гц. Микрофон обрабатывается локально, без записи и передачи звука в сеть. Выделение вокала и нот из песни пока экспериментальное; качество на разных жанрах, с хорами и эффектами не подтверждено контрольным набором файлов. Поэтому приложение показывает линию для визуальной тренировки, но не выставляет оценку по песне.
