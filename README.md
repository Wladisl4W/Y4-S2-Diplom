# Тренировка интонации

Локальное десктоп приложение для начинающих певцов. Оно показывает текущую ноту, отклонение в центах и историю высоты голоса. Есть две короткие распевки с примером, обратной связью и локальной историей занятий. Анализ MP3 пока исследуется и не выдаёт непроверенную нотную линию.

## Запуск

Нужен JDK 21. Для запуска из исходников выполните `./gradlew run` (Windows: `gradlew.bat run`). При первом запуске Gradle загрузит зависимости. Выберите микрофон и нажмите **«Начать микрофон»**. Во вкладке **«Живой голос»** отображаются нота и график. Во вкладке **«Распевки»** выберите упражнение, при желании прослушайте пример, затем нажмите **«Начать распевку»**. Через двухсекундный отсчёт пойте показываемые ноты. Результат сохраняется только на вашем компьютере в `~/.intonation-trainer/progress.csv`.

Микрофон должен поддерживать моно PCM 44,1 кГц. Если приложение не видит устройство, проверьте разрешение на микрофон в настройках ОС и обновите список. Для смены устройства сначала остановите микрофон.

## Разработка и проверка

`./gradlew test` выполняет тесты детектора, нотной шкалы, графика и упражнений. `./gradlew build` собирает приложение и запускает тесты. Пользовательские аудиофайлы и локальные результаты исключены из репозитория.

Документы: [архитектура](docs/architecture.md), [дизайн](docs/design.md), [методика качества](docs/quality.md), [этапы](docs/roadmap.md), [эксперимент MP3](docs/mp3-experiment.md), [решения](docs/decisions/0001-java-local-processing.md).

## Пакеты

`./gradlew jpackageImage` создаёт автономную папку приложения, `./gradlew jpackage` — установщик текущей ОС. Для DEB на Linux требуется `fakeroot`. Ручной workflow в GitHub Actions собирает установщики трёх ОС как артефакты. Их необходимо проверить на реальном оборудовании перед публикацией релиза; порядок описан в [docs/releases.md](docs/releases.md).

## Ограничения

Первая версия рассчитана на один голос без аккомпанемента в диапазоне 80–1000 Гц. Микрофон обрабатывается локально, без записи и передачи звука в сеть. Анализ MP3 и пение по песне будут добавлены после проверки качества выделения вокала и извлечения нот на контрольных файлах.
